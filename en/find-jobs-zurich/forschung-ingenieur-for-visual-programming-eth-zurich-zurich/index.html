  • Duration: 3 to 6 months (depending on workload)

Project background

Programming remains dominated by textual syntax, imposing cognitive load on novices and widening the gulf between code and behavior. Existing visual systems help with syntax but often mirror abstract syntax trees, offer weak modularity, and rarely scale to real-world software. The Belvue project developed in the AST Lab aims to advance visual programming through a new visual programming paradigm that centers on direct manipulation of program state, live feedback, and example-centric workflows.

Job description

We are looking for a research engineer to help us develop the Belvue language. You will implement language features and developer tooling and work closely with the language designer.

  • Implement or improve features in the visual language program editor (which is bootstrapped in Belvue)
  • Add new features or maintain the language implementation in C++
  • Contribute to the user interface and language design
