Student assistant for IT quality assurance work (m/f/d)

20%, Zurich, temporary

To support research and teaching, the IT services of ETH Zurich operate as a service organization in a large and complex IT environment.

For a temporary assignment until the end of 2027 (with an option for extension), we are looking for 1. January 2027 or by appointment a student assistant for IT quality assurance work and tests (m/f/d).

Job description

As a support to our existing team, you will conduct software quality tests for the alpha phase. In doing so, you test the stability, functional completeness and browser compatibility of web and Windows applications according to specified test scenarios. You document and report inconsistencies found in appropriate tools. You will also help create and update test cases using modern tools such as Playwright.

Profile

  • You have experience in dealing with Microsoft Windows and preferably also with Apple macOS and mobile applications (iOS, Android).
  • You have a good technical understanding of Windows and web applications and have gained advanced practical experience in this field.
  • You also do not shy away from partially repetitive work. In addition, you are characterized by a reliable and structured working method and can flexibly contribute to various project phases.
  • Very good German skills in word and writing are required.
  • Simple programming skills for creating scripts and database queries are beneficial.

We explicitly address a student assistant or a person who wants to work one day a week. The workload is preferably full-time on an agreed day, with the days Tuesday or Wednesday ideal.
