Full description

About the Role You'll help improve and experiment with engineering projects that combine CAE/CAD tools with cloud and on-premises platforms, with the goal of a better Product Lifecycle Management (PLM) efficiency. You will work where CAD/CAE meets software and split your time between operational systems and proof-of-concepts developments What you'll do

  • Work on understanding and supporting 3DEXPERIENCE REST APIs data definition and integration to other systems such as Databricks or direct point-to-point integration
  • Design, build, and maintain low-code workflows in Synera that connect CAD, CAE and other tools for different purposes such as tooling layout optimization, engraving optimization.
  • Configure, test, and develop custom applications and validate the data that flows between them. Document lessons learned and help the IT Application Owner (Automotive) evaluate new development paths.
  • Analyze CAD/CAE data formats and structures, find quick wins, model them in diagrams, and propose first solutions for review.
  • Write scripts for pre- and post-processing and small automation tasks.
  • Do basic work on infra Azure Resources (VMs, storage, compute for simulation jobs) and estimate cost and usage. Optionally, support deployments on Google Cloud Platform.
  • Prepare datasets from CAD/CAE results and support surrogate-modeling and design-space exploration experiments.
  • Write runbooks, user guides, and short demos for engineering users.

Example Assignments

  • Part similarity search and parameter estimation: Build a similarity search over historical sold parts using their key dimensions, e.g., nearest-neighbor search in a normalized parameter space. Then propose interpolation or regression methods that estimate starting parameters for a new project from customer requirements across different Sika products.
  • AI-Driven Concept Design: Generative Geometry & Surrogate Simulation: Use our historical CAD and CAE data to explore AI methods that propose initial part geometries for new requirements. Train surrogate models that estimate simulation results (e.g., stress, stiffness) in seconds instead of running full solver jobs, which cuts design time and compute cost
  • Rule-based Part Analysis application: Develop a web application that guides engineers through Part Analysis: 3D model viewing, measurements, comments, accept/reject decisions, and suggested actions. The workflow is driven by business rules and tracks the state of each review. The stack is React/Next.js with a 3D rendering library (e.g., Three.js). Structured data goes in a relational database and 3D models and attachments in blob storage.
  • Finance application modernization: Help migrate a project-finance application that tracks project data and resources from a monolithic SQL Server + MS Access setup to a modern web application, following Sika architecture and security guidelines.

Your Skills and Experience Must have

  • MSc. in Mechanical, Computational or Aerospace Engineering, Computer Science, or a related field (MSc. students in their final semester would also be considered)
  • Basic CAD/CAE knowledge: modeling concepts, common tools, and solvers, structural (FEA) simulation.
  • Basic Python: scripting, file and data handling, and common libraries (pandas/Polars, NumPy, Streamlit/Flask)
  • Practical understanding of LLMs: usage patterns, tooling/agent harnesses, model selection, and enterprise constraints (data privacy, compute, governance)
  • Basic Git
  • Basic Linux/Unix command line (incl. WSL2)
  • Analytical mindset and concise, clear written communication; able to read and create technical and business diagrams
  • Business awareness, so can autonomously judge the value of tasks and align quickly in a fast-changing environment

Nice to have

  • Basic Concepts of Web Development (frameworks) + Serving
  • SQL + PostgreSQL + ORM (prisma preferred) basics
  • Familiarity with 3DEXPERIENCE/CATIA/SIMULIA, or with low-code/visual programming tools (Synera, n8n)
  • REST APIs
  • Interest in ML for engineering (surrogate models, generative design)
  • Infrastructure-as-Code (terraform)
  • Basic Concepts of Network
  • Enterprise Knowledge Language, C++, JavaScript/TypeScript, React.
