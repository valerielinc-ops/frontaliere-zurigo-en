Application process

  • Our performance engineers analyze High Performance Computing (HPC) applications with the intent of improving performance by driving compiler optimizations and library enhancements.
  • This role offers the chance to work with a wide range of applications, from small benchmarks running on single-CPU core to full-scale applications running on multi-node multi-GPU systems.
  • You'll find optimization opportunities and work closely with our compiler development and application engineering teams to deliver effective solutions. What you'll be doing:
  • Analyze the effect of different compilers and compiler optimizations on HPC application performance.
  • Evaluate whether and how the compiler and runtime can improve the performance of key HPC applications on CPU and CPU/GPU platforms.
  • Communicate limits of compiler capabilities with application engineering to guide the best path forward towards improving performance.
  • Port HPC applications to different platforms and programming models.
