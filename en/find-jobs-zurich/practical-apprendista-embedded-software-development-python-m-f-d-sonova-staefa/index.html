Practical Trainee (Embedded Software Development & Python) (m/f/d) — Sonova

This position is no longer active. Below you'll find the original details and other open positions.

Full description

We are looking for a self-driven Practical Trainee to support the development and integration of embedded software solutions for ASIC testing of hearing instruments. In this role, you will work closely with experienced engineers on real-life testing infrastructure challenges, including USB driver integration, embedded software development, hardware communication, and test automation. This traineeship offers hands-on experience in embedded systems and Python development within an innovative industrial environment.

More about the role

As a Practical Trainee in Embedded Software Development & Python, you will support activities such as:

  • Familiarizing yourself with the existing ASIC testing infrastructure and hardware setup
  • Supporting the integration of a USB to I2C converter chip into a Python-based test framework
  • Developing and implementing embedded software components and communication drivers
  • Creating Python wrappers and automation scripts for hardware interaction and testing
  • Investigating and implementing efficient interrupt handling and power management solutions
  • Collaborating with engineers to evaluate alternative technical solutions when required
  • Supporting testing, debugging, validation, and documentation of developed software components
  • Assisting with synchronization and integration activities between different hardware and software systems
  • Optionally supporting CI pipeline integration and test automation improvements

More about you

  • Bachelor’s or Master’s student (ongoing or recently completed) in Electrical Engineering, Embedded Systems, Computer Engineering, Software Engineering, or a similar field
  • Good Python programming skills
  • Basic experience with embedded software development and hardware communication
  • Understanding of hardware interfaces and communication protocols such as USB or I2C
  • Familiarity with C/C++ and Linux or Windows environments is a plus
  • Structured, analytical, and proactive way of working
  • Fluent communication skills in English and ability to work independently

More about What We Offer

As a leading global hearing care provider headquartered in Switzerland, we foster an inclusive and collaborative culture. We support work-life balance through a flexible hybrid working model and offer strong learning opportunities, individual development plans, and clear growth paths within R&D.

  • Hands-on experience with real embedded systems and hardware testing environments
  • Coaching and mentorship by experienced engineers
  • Exposure to ASIC testing infrastructure and industrial software development processes
  • International and multidisciplinary working environment
  • Opportunity to work on innovative technologies related to hearing instruments
