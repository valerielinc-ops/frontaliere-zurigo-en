Main responsibilities

  • Design, develop, and maintain scalable and reliable server-side infrastructure for the automotive AI agent platform using C++ and Go.

  • Implement and integrate Google Cloud technologies and best practices, including control plane framework engine (CCFE), and ensure compliance with security and privacy horizontals (e.g., access transparency (AxT), customer-managed encryption keys (CMEK), virtual private cloud service controls (VPC-SC), data residency zones (DRZ)).

  • Write well-tested, production-ready code and participate in on-call rotations to support service reliability.

Key requirements

  • Bachelor's degree in Computer Science or related technical field, or equivalent practical experience.
